## 输出物

1. `tests/windows_teardown.py`：测试专用清理助手。三个公开入口 `terminate_and_wait`（terminate → 有界 wait → kill → PID 轮询确认退场）、`cleanup_temporary_directory`（先退场再重删临时根）、`resilient_rmtree`（幂等 + 有界退避）；另有 `temporary_root` 返回父目录已 resolve 的规范临时根，避免 8.3 短名别名。`sleep` / `monotonic` / `pid_probe` / `rmtree` 全部可注入。
2. `tests/test_windows_teardown.py`：16 项注入式单测（无需真实时间与真实进程，1.26s 跑完），覆盖首删成功返回 0、退避次数与 sleep 序列、deadline 耗尽后仍抛原始 `PermissionError`、非可重试异常立即透传、进程先于清理退场的顺序、路径已消失的幂等。
3. 四处高危夹具收编：`tests/test_install_scripts.py`（进程映像就在临时根内，改用退场确认 + 有界重删）、`tests/test_continuation_execution.py`（删除私有 `_cleanup_tempdir`，改为共享实现并给进程树用例补父进程退场确认）、`tests/worktree_scenarios.py`（`TemporaryWorktreeScenario.close()` 改为有界重删，覆盖 worktree 批次公共入口）、`tests/test_release_license_metadata.py`（`uv build` 产物落在临时根，改为同上清理）。
4. 零产品变更的证据：命令树快照 `tests/fixtures/cli_surface.json` 无漂移（`tests.test_cli_surface_snapshot` 通过），`acf version show` 仍为 v0.0.3.100，README/CHANGELOG 不动。
