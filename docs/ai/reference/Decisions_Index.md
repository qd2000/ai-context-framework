## 使用规则

1. 先阅读本索引，再决定是否打开具体 ADR。
2. 不要重复推进已否定方案，除非用户明确要求重新评估。
3. 如果索引和旧 worklog 冲突，以本索引为准。
4. 如果需要理解决策原因，请读取对应 ADR 文件。
