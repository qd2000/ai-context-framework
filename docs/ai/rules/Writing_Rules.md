本文件记录本仓库文档写作规则。

---

## 通用要求

1. 文档默认使用中文。
2. 文件名和目录名使用英文。
3. 不把 `template/` 占位内容当作本仓库事实。
4. README 面向使用者，System Manual 面向项目内维护者和 AI。
5. worklog 是历史过程记录，不是当前事实源。

---

## 同步要求

1. 修改模板结构时，同步检查 README、模板 AGENTS 和模板 System Manual。
2. 修改 dogfooding 事实时，同步检查当前 Context。
3. 重要实现过程或评测发现应写入 daily worklog。
4. 未整理的人类反馈先进入 `active/Feedback_Inbox.md`，不要直接伪装成已确认事实。
