## 边界说明

本 Workstream 使用强隔离协作协议。AI 执行前应先运行 `acf workstream context WS010` 获取专属上下文入口；完成、ready、done 或切换状态前，应优先运行 `acf workstream guard WS010 --files <本次修改文件...> --json` 对本次文件集做强验收。裸 guard / `--from-git` 只用于快速查看当前 git diff；旧式整工作区排他检查需显式使用 `--workspace --strict-workspace`。

- `read_scope` 是允许读取的默认上下文入口。
