## 目标

1. `doctor` 能区分 `active_live`、`stale/orphan_candidate`、`expired` 与需要 reconciliation 的状态，不再把 TTL 当作 runner liveness。
2. lease 引入 generation/fence ownership；旧 runner 在新 generation 生效后不得 renew/checkpoint/release。
3. 为 non-idempotent 外部工作提供 bounded write-ahead effect identity/milestone journal，恢复时复用 terminal/collected/aggregated evidence，禁止重复 submit/collect。
4. 提供正式 `reconcile/recover` 路径；只有能证明安全的 orphan 才允许 takeover，未知副作用、dirty Git、不可解释 HEAD 或 live/queued identity 一律 fail-closed。
5. 修复 `waiting_external` 等显式状态被 clean release 默认覆盖为 `ready` 的语义缺陷，并改善 wrong task-id / issue lifecycle 等已暴露 UX 问题。
6. 保持长 bounded Gate 正常使用 renew，不以人为缩短 Gate 作为异常恢复手段；兼容既有 v0.0.3.61 state/control/lease 数据并用 WS079/WS086 dogfood 证据验收。

## 当前发现

- WS086 真实 Scheduled Task 已复现 active lease orphan：科学 Gate 的 exact waves、Campaign、collect 与 aggregate 均已 durable 完成，但会话在 test/Git/checkpoint/release 前终止；下一 runner 缺少正式 orphan reconciliation 入口。
- v0.0.3.61 的 lease liveness 仅由 `expires_at > now` 决定；没有 heartbeat、stale-active/orphan classification、generation 或 fence token。
- 当前 `renew/checkpoint/release` 只校验 `lease_id`，没有 owner/fence generation 约束；这意味着旧 lease identity 一旦泄露给新 runner，控制面存在 split-brain 风险。
- v0.0.3.60 的 expired-head guard 只能识别 Git HEAD 前进；WS086 证明 Git clean/HEAD unchanged 并不代表外部 Runtime/Campaign 没有发生 durable side effects。
- WS079 已记录 `checkpoint --status waiting_external` 后 clean `release` 又把状态改回 `ready` 的真实问题。
- ACF v0.0.3.61 已具备 `continuation issue` / `log issues`，后续 WS007 及并行任务暴露的问题继续进入结构化 dogfood issue 池。
