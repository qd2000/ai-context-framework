## 当前发现

- ACF v0.0.3.62 已解决 TTL-active 不等价于 runner liveness、stale/orphan classification、generation fencing、durable effect journal 和 formal reconcile/recover；但 `reconcile` 对 `git_clean=false` 仍整体 fail-closed，不能区分“旧 runner 自己留下的 WIP”“claim 前已存在的人工/无关 dirty”“claim 后出现但与当前 Gate 不重叠的外部 dirty”和真正冲突。
- blanket `worktree_dirty` 规则会把无害 dirty 误判为并发冲突。目标规则应是：非重叠 dirty 永远保留且不阻塞；只有同路径/父子路径碰撞、未声明写入、不可解释 HEAD、未解决 side effect 或所有权证据漂移才阻塞。
- 当前 heartbeat stale threshold 与 `renew_interval_minutes` 绑定；长 Gate 应允许 heartbeat/stale 与 lease renewal 分离。目标是支持 1-2 小时甚至更长的单轮执行，而不是通过缩短 Gate 规避异常。
- 当前各项目 Scheduled Task 仍复制了不同版本的 generic recovery 文案。应改为“项目 wrapper + 每轮读取当前 `acf continuation prompt`”，让 ACF 成为唯一通用协议权威，项目文档只保留项目特有的 Runtime/科学/权限约束。
