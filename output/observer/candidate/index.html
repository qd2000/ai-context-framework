S2 已暴露的第一批真实减法点

不是凭抽象偏好重构，而是由 S1 实际使用反推。

候选页实际不需要

  • Target Registry 才允许展示对象的 gate。
  • primary_visualization kind/spec 才允许选图。
  • 每次刷新都先走 semantic-review / Map Review lifecycle。
  • ACF deterministic renderer 才能生成或重排 HTML。
  • 统一 shell、固定卡片和固定图形枚举。

仍值得保留 / 降为可选

  • Continuation ownership / effect / fencing / Git 安全合同。
  • 只读项目导航、run/history、来源和健康信息。
  • 旧历史的兼容读取，避免不可再生证据丢失。
  • 简单原子文件/历史 helper（若真实调用者仍需要）。
  • Production anti-masking 与真实 run identity。
当前可复现摩擦： 安装态 acf continuation prompt 仍输出旧 Production Observer wrapper contract，例如 display_scope_source=explicit_user_level_target_registry、 semantic_review_required_each_refresh=true、 map_review_gate_required_for_semantic_risk=true。 这些与最新 Agent-first authority 已发生语义冲突，是 S2 优先审查对象；但 Writer continuation 的 ownership/effect/fencing 合同不能随之误删。
